About the rebuild

A static kwaBulawayo built for speed.

This version replaces the old WordPress stack with a static front end. It keeps the listing usefulness, editorial warmth, and map-ready location data while making deployment simpler on Cloudflare Pages.

What was replicated

Searchable listings, category browsing, location detail pages, Google Maps handoff, and a city-guide presentation layer.

What improved

Cleaner front-end code, lighter pages, R2-hosted images, no plugin lock-in, and a structure that is easier to extend with editorial collections and forms.

kwaBulawayo
